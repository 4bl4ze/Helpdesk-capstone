The six rules

Every decision below follows from these. If a new screen breaks one, the screen is wrong, not the rule.

  1. Colour is never the only signal. An SLA breach is red and carries a ✕ and says “Breached”. Roughly one man in twelve cannot separate our red from our green, and a lecture-hall projector washes out both.
  2. Verified contrast, not guessed. Every text pair here is ≥4.5:1; every control border and focus ring ≥3:1. Numbers are printed on the swatches.
  3. No web fonts, no icon fonts. DeskTrace is offline-first (FR-OFF-01). A font that fails to load is a broken screen, so we use the system stack and text glyphs.
  4. Body and form text is 16px. Below 16px, iOS Safari zooms the page when a field is focused — unusable for a requester filing a ticket one-handed.
  5. Touch targets are at least 44×44px. Technicians use this standing up, in a corridor, holding equipment.
  6. Three signals, three languages. Status is a word, priority is a shape, SLA is a colour. They never compete for the same attention.

What changed in v2

v2 is a visual refresh, not a rewrite. Every class name is unchanged, so anything already built against v1 keeps working — a design system that renames its API on every restyle is not a system. All six rules above survived intact, and the whole palette was re-verified: 44 pairs, all passing.

Kept

System fonts, 16px inputs, 44px targets, verified contrast, and colour never alone. These are requirements, not taste — FR-OFF-01 and WCAG don't move because the look did.

Resisted

Web fonts, icon libraries, glassmorphism over content, and low-contrast grey-on-grey text. All currently fashionable; all break a rule above.

Status signals — the important part

DeskTrace shows three different things about a ticket at once. If all three used colour, the screen would be noise. So each gets its own language.

1 · Ticket status — a word

Neutral on purpose. Six statuses cannot be told apart by colour anyway, and the word is unambiguous. Two carry a glyph because they change the SLA clock.

New Assigned In Progress Waiting Resolved Closed

2 · Priority — a shape

A four-step meter. Severity is read from how many bars are filled, so it survives greyscale, colour blindness and a washed-out projector. Only Critical also takes colour.

Low Medium High Critical

3 · SLA state — colour, icon and word together

The only place colour carries meaning. Never ship one of these without its icon and its label.

Controls

Buttons

One primary action per screen region. 44px minimum height; full width when stacked on a phone.

Tabs

A pill that moves, rather than an underline. Scrolls horizontally on a phone without a scrollbar.

Segmented control

For urgency. One tap instead of opening a dropdown — and each option shows the response target it commits to, which is the cheapest brake there is on everyone declaring their fault Critical.

Form fields

Up to three photos can be attached. They are compressed before saving.

Charts

Horizontal bars, one series per panel. Category names here are words, not dates, and a horizontal bar gives a label room to be read instead of rotated. One series means the title already names what is plotted, so there is no legend. The series colour is the accent, never the SLA colours — green, amber and red are reserved for state, and a chart that borrowed red would stop "red" meaning "breached".

Data table

Bulk audit and comparison is a table task, not a card task. Tables stay tables on a phone — wrap in .ds-table-scroll and let them scroll sideways rather than collapsing into unreadable stacks.

Responsive rules

Mobile-first. The requester journey is designed for a phone held one-handed in a corridor; the manager dashboard is designed for a desktop.

BreakpointWidthWhat changes
Base< 600pxOne column. Buttons go full width when stacked. Filters collapse behind a disclosure. Dashboard charts scroll horizontally rather than shrink.

How to use this

In the prototype: add <link rel="stylesheet" href="design-system/desktrace.css"> and swap the old class names for the ds- ones.

In the React app: import './design-system/desktrace.css' once in main.jsx. Never write a raw hex value or pixel size in a component — if a token is missing, add it here instead.

Owned by the UI/UX pair. Changes to this file go through a pull request like any other, so the visual language stays one thing.
